## О проекте

Это небольшая система для кофейни. Баристы отмечают приход и уход и закрывают задачи на смену, а управляющий составляет график, смотрит, кто опоздал или ушёл раньше, и считает зарплату за месяц. Данные лежат в PostgreSQL, сверху сделано простое веб-приложение на Flask.

## На каком этапе работа

## Исследовательская часть коротко

**СУБД.** Выбрал PostgreSQL. Мне были нужны ENUM для статусов, триггеры и функции на PL/pgSQL, чтобы правила учёта времени жили в самой базе, а не в приложении. Сравнение с другими вариантами есть в разделе 7.1 документа. Писал и проверял под версию 16, у меня на компьютере стоит 18, тоже работает.

**Модель данных.** Шесть таблиц: employee, shift, schedule, time_record, task, payout. За основу взял концептуальную схему, которую мы уже согласовывали, и при переходе к логической схеме немного поменял её:

- фактическое время разделил на actual_start и actual_end;
- в payout добавил hours, bonus и penalty, чтобы можно было видеть из чего получилась сумма;
- график (schedule) связан со сменой (shift) по дате, без отдельного внешнего ключа.

**Правила, которые считает сама база.**

- Опоздание или уход раньше плана больше чем на 10 минут считается нарушением.
- Штрафы: опоздание 200 ₽, ранний уход 200 ₽, прогул 500 ₽.
- Итог за месяц: часы × ставка + премия − штрафы, но не меньше нуля.
- Закрытую смену нельзя менять, это проверяет триггер.

## Как запустить

Нужно: PostgreSQL 16 или новее (чтобы работала команда psql), Python 3.8 или новее и Flask (`python -m pip install --user flask`).

Я запускал на Windows 10, сервер PostgreSQL 18, клиент psql 16. Команды для cmd:

```
set PGCLIENTENCODING=UTF8
psql -U postgres -c "CREATE ROLE worktime LOGIN PASSWORD 'worktime'"
psql -U postgres -c "CREATE DATABASE worktime OWNER worktime ENCODING 'UTF8' TEMPLATE template0 LC_COLLATE 'C' LC_CTYPE 'C'"
psql -U postgres -d worktime -f sql\00_all_in_one.sql
psql -U postgres -d worktime -c "GRANT ALL ON ALL TABLES IN SCHEMA public TO worktime; GRANT ALL ON ALL SEQUENCES IN SCHEMA public TO worktime; GRANT ALL ON ALL FUNCTIONS IN SCHEMA public TO worktime"
cd app
set PGPORT=5432
set PGPASSWORD=worktime
python app.py
```

После этого открыть в браузере http://localhost:5050.

Если psql пишет, что не может подключиться под postgres, проверьте, что в этом окне не задана переменная PGPASSWORD с другим паролем (она подставляется автоматически). Роль и пароль worktime учебные.

Что можно посмотреть в приложении:

- /barista: рабочее место бариста (приход, уход, задачи на смену);
- /manager: панель управляющего (график, смены, нарушения, выплаты, премии);
- /employees: сотрудники и их ставки.

В приложении «сегодня» зафиксировано как 22.11.2026, потому что на эту дату сделаны демо-данные. Время прихода и ухода для проверок можно задавать в адресе, например `/barista?emp=1&at=08:25`.

## Что пока не сделано

- Нет авторизации, сотрудника просто выбирают из списка.
- Ставка у сотрудника одна, истории изменений нет. Если пересчитать уже посчитанный месяц после смены ставки, итог поменяется.
- К базе приложение обращается через psql, а не через драйвер, потому что так было проще настроить.
- Сотрудников, задачи и смены можно добавлять, но нельзя редактировать или удалять из интерфейса.
